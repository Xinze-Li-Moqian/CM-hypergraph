# Definition — gradient

## Statement

> [!definition] Gradient
> For a smooth function $f$ on a Riemannian manifold $(M, g)$, the *gradient* $\nabla f$ is the vector field $g$-dual to $df$:
> $$
> g(\nabla f, X) \;=\; df(X) \quad \text{for all vector fields } X .
> $$
