# The min-max route to finite extinction of Ricci flow

How sweepouts by $2$-spheres force the Ricci flow with surgery to die in finite time: the width, its evolution inequality, and the extinction they force.

A **pre-formalization network**: the argument written out in prose, with every
statement it turns on as a separate addressable card, and the dependencies
between those statements as edges. 10 sections, 103 statements,
292 edges.

## Reading it

Clone the repository, or download the ZIP and unpack it, then open the folder
as an Obsidian vault — stock Obsidian, nothing to install.

Every statement is one Markdown file under `*Hypergraph/atoms/`, filed by
what it is; every relation between two statements is one file under
`*Hypergraph/edges/`. The prose cites them with `![[embeds]]` and
`[[wikilinks]]`, which is why this reads as a network in Obsidian rather than
as a document with a bibliography. `*Hypergraph/rules.md` states the
conventions the cards follow, and `notation.md` maps each symbol to the card
that defines it.

## What it contains

**Every statement is self-contained.** Each card's Statement links only to
cards that are in this repository, so a term can always be followed to where it
is defined. Proofs and commentary sometimes reach further — 132
links point at machinery that is not part of this argument, and Obsidian renders
those faded.
